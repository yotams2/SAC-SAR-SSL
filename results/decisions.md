- **2026-11-23, V1 room teacher: a LEARNED RIR encoder (A′) is the published teacher; the oracle parameter teacher B is an analysis row only.** A′ needs only RIRs (simulated or measured, no labels); B (z-scored simulator TDOA, T60, DRR, C50, room volume, source-mic distance) needs ground-truth room parameters, which real data almost never has, so B is reported as "oracle SAC", an upper bound on how good the teacher's soft weights can be. V1a's spatial side only ever uses a learned teacher (V1a with B would be supervised regression of the evaluation targets); V1a's spectral side (dry-speech teacher) is unchanged. Two masked-reconstruction RIR encoders (v1: whole-RIR STFT; v2: early STFT + late envelope, per-channel tokens) carry no TDOA (held-out 2.86 samples = mean predictor) because nothing in their objective needs the inter-channel relation and mean pooling dilutes the direct-path tokens; A′ fixes the objective (cross-channel), the input (the student's ipd16) and the pooling (attention over early tokens). Pass test (revised 23 Nov): TDOA MAE <= 1.95 samples (2x the best Step-0 hand-feature linear readout, 0.97; ridge on early ipd16 + GCC-PHAT; this is a linear-readout reference, not a ceiling for a learned encoder, which can compute the delay nonlinearly), T60 / DRR / C50 no worse than the same encoder at random init (0.015-0.016 / 1.12-1.22 / 0.41-0.47; v2 reported alongside), Spearman of embedding vs true-parameter distances reported. "Useful as a teacher" = TDOA <= ~1.3 (at or better than C2 seed 1's 1.24; students: C 2.23-2.38, C2 1.24 / 1.97). Pass + useful -> A' is the V1 room teacher; pass but not useful -> report and propose design 2 (GCC-PHAT tokens as an extra input stream; GCC-PHAT was the best single hand feature for TDOA); fail -> design 2. At most two designs; then stop and decide. **Thesis framing:** V1 with a learned RIR teacher is still learning with privileged information (it needs each training clip's RIR, simulated or measured, but no labels); the oracle B row bounds it from above; V3 (unpaired) is the from-the-wild version.
